# Theranet HR & Operations Module Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the Shift, Attendance, Leave, Payroll, and Performance Review systems natively into Theranet.

**Architecture:** Database-first implementation using Supabase migrations, adding new syncing tables to Dexie, and exposing simple UI components on the Therapist Workspace and Admin Team dashboard.

**Tech Stack:** React, TypeScript, Supabase, Dexie, Tailwind CSS

**Spec:** `docs/superpowers/specs/2026-09-26-theranet-hr-module-design.md`

## Global Constraints
- Every new table must be added to `ALL_SYNCED_TABLES` in `src/lib/db.ts`.
- All writes must work offline-first via the Outbox pattern.
- RLS policies must strictly isolate therapist data, while giving full read/write to `is_clinic_admin()`.

## Review Focus
- Location flagging fails to attach coordinates when GPS times out, but correctly logs the clock-in anyway.
- Generating payroll handles edge cases where the therapist has zero visits but a fixed base salary.
- Admins viewing performance reviews correctly sees calculated `Net Clinic Profit` without errors even if zero revenue.

- [ ] **Step 2: Create hrService.ts**
Implement the offline-first mutations.

```typescript
import { db } from '@/lib/db';
import { v4 as uuidv4 } from 'uuid';

export const hrService = {
  async clockIn(clinicId: string, therapistId: string, lat?: number, lng?: number, outOfBounds = false) {
    const id = uuidv4();
    await db.putLocal('attendance_logs', {
      id,
      clinic_id: clinicId,
      therapist_id: therapistId,
      clock_in_time: new Date().toISOString(),
      location_lat: lat,
      location_lng: lng,
      is_out_of_bounds: outOfBounds
    });
    return id;
  }
};
```
